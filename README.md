## Project Title: Your To-Do App

[tutorial](https://www.digitalocean.com/community/tutorials/build-a-to-do-application-using-django-and-react)


### Description:

This is a to-do application built using Django (backend) and React (frontend). It allows users to create, edit, and delete tasks, as well as mark them as completed.

### Key Features:

- Task creation, editing, and deletion
- Task completion tracking


### Technologies Used:   

- Backend: Django, Python, Django REST framework
- Frontend: React, JavaScript, CSS, HTML
